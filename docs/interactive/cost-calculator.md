## 输入参数

- **数据集规模**：训练集图像总数（COCO train = 118,287 张；自有场景常见 1k / 10k / 100k）。
- **平均目标数 / 张**：影响 anchor 分配与 loss，10 → 200 目标约 1.6× 时长。
- **输入分辨率**：416 以下多为边缘端；640 是甜蜜点；1280 以上显存与耗时都 ×4 起步。
- **模型档位**：n / s / m / l / x 分别对应 2.8M / 9.4M / 21.8M / 63.6M / 84.7M 参数。

## 估算模型假设

- 参考基线：**yolo26n + 640 + batch32 + 单 A100 = 1 epoch 约 1.8 小时**；参数量、分辨率、batch、数据量、目标数、AMP、GPU 性能、多卡效率按**独立因子相乘**。
- 数值来自社区基准 + 团队实测，实际训练与估算偏差常在 ±30% 以内，极端可到 ±2×。

## 局限性

- **数据增强**：Mosaic / Mixup / Copy-Paste 从默认开到激进，训练时长可 ×2。
- **混合精度**：AMP 省 30-50% 显存、加速 1.5-2×，本工具按 0.6 因子估算。
- **GPU 利用率波动**：数据加载瓶颈、CPU 单核不足时利用率掉到 40%，时长可 ×2。
- **多卡扩展非线性**：8 卡实际效率约 0.65×，NCCL 通信瓶颈明显。

## 什么时候用 / 不要用

- **用**：采购决策前的量级估算 / 立项答辩 / 训练前判断 OOM / 教学分享。
- **不要用**：招标级报价（必须 benchmark）/ 单卡 vs 多卡决策（必须真实 DDP）/ 数据管道瓶颈（用 PyTorch Profiler）/ 长期训练（>30 天）。
